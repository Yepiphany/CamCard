# 阶段任务

各节记录对应阶段的实现与验证状态。扫描、备注及回归测试的后续结果汇总在[第六阶段补查记录](stage-6-acceptance.md#第六阶段补查记录)。

| 阶段 | 任务 | 完成标准 |
| --- | --- | --- |
| 1 | 建立本地仓库与远端，梳理黑盒行为、需求、数据模型和测试计划 | 基础文档完成，参考证据与未观察行为可区分，测试用例可追溯到需求。 |
| 2 | 初始化 Xcode 工程，建立导航、模型、存储接口、空名片夹和模拟数据 | 模拟器可构建启动，首页与详情导航有可复现的验证步骤。 |
| 3 | 实现扫描入口、相机、导入、边界检测、校正和 OCR | 导入样本可得到校正结果及 OCR 原始输出，能取消或处理错误。 |
| 4 | 实现结构化字段提取、人工校对与保存 | 支持多值与缺失字段，人工确认后保存，并按固定样本统计识别准确率。 |
| 5 | 实现搜索、分组、备注、编辑、删除、持久化及导出 | 模拟器可验证重启恢复、管理操作和导出映射。 |
| 6 | 执行验收及回归，归档差异、截图和 AI 协作记录 | 汇总各用例证据、OCR 差异及相机验证范围，完成课程演示。 |
