# 原版黑盒规格

参考对象为 2026-11-05 通过 iPhone 镜像观察的简体中文、未登录状态的名片全能王。原版版本号、iPhone 机型及系统版本未记录。

| 场景 | 已观察行为 |
| --- | --- |
| 名片夹空状态 | 底部「名片夹」进入列表页。顶部有搜索框和分组入口。空状态显示 0 张名片和入门引导。 |
| 扫描 | 底部居中的相机按钮打开深色扫描页。页面有关闭、取景框、快门和相册入口。观察到基础识别与 AI 高精度识别的切换，后者的服务行为待核对。 |
| 导入 | 仅授权部分照片时显示授权范围提示。选择图片后，「完成」旁显示已选数量。点击完成后自动校正、识别并进入编辑页。 |
| 编辑与校正 | 编辑页顶部有重新拍摄和保存，预览中显示文字高亮。点裁剪按钮进入原图调整页，蓝色边框带四角及四边控制点，顶部有取消和完成。观察到取消返回编辑。 |
| 保存 | 保存先打开名片详情。返回名片夹后，列表出现新增名片，显示日期、缩略图、姓名、职位和公司。 |
| 详情与管理 | 详情有编辑、备注、未分组行和通讯录入口。更多菜单显示分组、备注、删除等操作。点击未分组行进入添加到分组页，包含搜索及新建分组入口。 |
| 导出权限拒绝 | 点击保存到通讯录触发系统权限提示。拒绝后显示无法保存，并提供前往设置的入口。 |
| 搜索入口 | 从名片夹点击搜索框进入搜索页。观察时公开人脉搜索开关处于关闭状态。 |

后续观察需覆盖手动裁剪完成后的变化、字段编辑和放弃、搜索匹配、分组保存和筛选、备注、删除、重启恢复、导出成功以及相册拒绝。搜索词匹配规则、导出字段映射与错误处理需以观察及课程要求补足。镜像无法使用 iPhone 相机，真实预览和拍摄未观察。记录观察结果时使用脱敏信息。
