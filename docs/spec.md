# 原版黑盒规格

参考对象为 2026-11-05 通过 iPhone 镜像观察的简体中文、未登录状态的名片全能王。原版版本号、iPhone 机型及系统版本未记录。

| 场景 | 已观察行为 |
| --- | --- |
| 名片夹空状态 | 底部「名片夹」进入列表页。顶部有搜索框和分组入口。空状态显示 0 张名片和入门引导。 |
| 扫描 | 底部居中的相机按钮打开深色扫描页。页面有关闭、取景框、快门和相册入口。观察到基础识别与 AI 高精度识别的切换，后者的服务行为待核对。 |
| 导入 | 仅授权部分照片时显示授权范围提示。选择图片后，「完成」旁显示已选数量。点击完成后自动校正、识别并进入编辑页。 |
| 编辑与校正 | 编辑页顶部有重新拍摄和保存，预览中显示文字高亮。点裁剪按钮进入原图调整页，蓝色边框带四角及四边控制点，顶部有取消和完成。观察到取消返回编辑。 |
| 保存 | 保存先打开名片详情。返回名片夹后，列表出现新增名片，显示日期、缩略图、姓名、职位和公司。 |
| 详情与管理 | 详情有编辑、备注、未分组行和通讯录入口。更多菜单显示分组、备注、删除等操作。点击未分组行进入添加到分组页，包含搜索及新建分组入口。 |
| 导出权限拒绝 | 点击保存到通讯录触发系统权限提示。拒绝后显示无法保存，并提供前往设置的入口。 |
| 搜索入口 | 从名片夹点击搜索框进入搜索页。观察时公开人脉搜索开关处于关闭状态。 |

## 补充观察

| 场景 | 2026-11-05 实测行为 |
| --- | --- |
| 搜索命中 | 用英文公司名的部分文本查询，输入全小写仍匹配含大写的公司名。「综合」显示「名片夹名片」区块、命中计数及高亮词。结果行显示缩略图与联系信息。 |
| 搜索无命中 | 输入无匹配词并切到「名片」页签，显示带搜索词的空状态，提示检查输入或换词。 |
| 创建分组 | 名片夹 → 分组管理 → 新建分组。名称为空时确认不可用。填写并确认后，「我的分组」出现新分组，计数为 0。 |
| 添加组员与筛选 | 点击空分组 → 右上角更多 → 从名片夹中添加 → 勾选名片 → 完成。返回组内列表后计数从 0 变为 1，显示所选名片。打开该条目，详情显示分组名称。 |
| 普通备注 | 详情 → 备注 → 新增备注 → 普通备注。输入文本并保存后，返回备注列表，显示文本及时间。 |
| 通讯录导出 | 再次点击「存入通讯录」仍显示「无法保存名片到通讯录」和权限设置入口。授予权限后进入下述成功路径。 |
| 通讯录导出成功 | 名片详情 → 存入通讯录 → 保存到通讯录。iPhone 目标默认勾选，确认后返回名片详情。在系统「联系人」中找到导出的条目，核对姓名、公司、职位、手机、工作邮箱、主页和工作地址。双语公司和职位文本均保留，主页带协议前缀。 |

上述搜索样本验证了英文公司名部分匹配和大小写处理。姓名、职位、电话、邮箱的具体匹配规则仍待对照。手动裁剪完成后的变化、字段编辑和放弃、删除、重启恢复及相册拒绝也待观察。镜像无法使用 iPhone 相机，真实预览和拍摄未观察。记录观察结果时使用脱敏信息。
