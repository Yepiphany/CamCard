# 项目需求

依据《移动应用开发课程作业 v2》和项目确认事项。本项目面向需要将纸质名片转为可查询、管理和导出联系人的 iOS 用户。

## 功能范围

| 编号 | 要求 |
| --- | --- |
| R01 | 名片夹显示空状态或名片列表，提供扫描、搜索、详情与管理入口，保存和删除后更新列表及计数。 |
| R02 | 支持实时相机预览和拍摄、重拍、取消以及相册导入。处理权限拒绝和流程中途退出。 |
| R03 | 自动检测名片边界并裁剪，进行透视与方向校正，支持手动调整、确认和取消。 |
| R04 | 使用 Apple Vision 识别中英文及混排文字，保留原图、处理图和 OCR 原始输出。 |
| R05 | 结构化提取姓名、公司、职位、手机、办公电话、邮箱、网站和地址。允许多电话和多邮箱。对未出现或无法确认的字段留空。 |
| R06 | 保存前展示图像及识别字段，支持人工修改、添加或清空值，保留识别结果与最终值的区别。 |
| R07 | 保存后可查看详情及原始名片，编辑、删除，打开系统电话、邮件和网站入口。 |
| R08 | 按姓名、公司、职位、电话和邮箱搜索。支持新建分组、加入分组、按组筛选、删除分组及编辑备注。 |
| R09 | 本地持久化图像、字段、分组和备注，应用终止并重启后仍可打开。 |
| R10 | 支持存入系统通讯录和导出 VCF，分别验证姓名、公司、职位、电话、邮箱、地址的映射。 |

注册、订阅、支付、广告、云同步、公开人脉搜索、团队名片库、数字名片和 CRM 同步排除在本次功能切片之外。原版仅通过正常使用观察外部行为，使用项目自建资源实现界面。

## 验收范围

- 确定性场景按可复现的参考规格比较布局、跳转、状态、数据与异常路径。
- OCR 和字段提取用固定名片集与标准答案评估。记录原始输出、解析结果、人工修订、字段级准确率和与原版的差异。
- 运行验收使用 Xcode 模拟器，通过导入测试图片覆盖识别、校对与保存流程。相机实时预览、拍摄和补光已接入，真机运行仍未验证。
- 原版版本不预先指定。取得实际版本及环境信息时记录在观察证据中。

项目采用[合成名片测试集](../tests/fixtures/business-cards/README.md)。模拟器验收使用 iPhone 18 Pro 和 iOS 27.2。通过课程平台提交源码和课程报告。
