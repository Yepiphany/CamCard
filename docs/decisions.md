# 项目决策

| 编号 | 决策 | 原因与验证 |
| --- | --- | --- |
| D01 | 工作按阶段推进。 | 每阶段以可验收结果作为结束条件。 |
| D02 | 使用 Swift、SwiftUI 和 Apple Vision，名片与图片保存在本地。 | 识别及管理流程可在设备端运行，模拟器使用照片验证识别。 |
| D03 | 原版通过 iPhone 镜像观察，复刻应用仅通过 Xcode 模拟器验收。 | 版本无需预先指定，记录实际观察环境。相机实时预览和拍摄保留在实现范围，实拍标记未验证。 |
| D04 | 使用项目生成的合成名片及字段答案。 | 29 张用于计分，另外两张用于严重失焦和无名片异常路径。 |
| D05 | 同时实现存入系统通讯录和 VCF 导出。 | 通讯录路径对齐原版入口，VCF 提供独立的文件出口。两个出口共用字段映射并分别验收。 |
| D06 | 使用私有 GitHub 仓库，分批验证并提交。 | 推送限定为用户确认的提交。 |

课程交付已确认为通过课程平台提交源码和报告，见[交付计划](plan.md)。

第二阶段将最低部署版本设为 iOS 17.0，当前运行验证使用 iOS 27.2。使用 Codable 值类型描述记录，由存储接口隔离界面与数据来源。第二阶段注入内存存储，默认数据为空。第五阶段接入本地持久化并验证跨启动恢复。
