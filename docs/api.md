# 应用内部接口契约

本项目使用进程内模块接口。以下名称描述职责，阶段 2 随工程确定 Swift 类型签名。

| 接口 | 输入 | 输出或失败 |
| --- | --- | --- |
| ImageSource | 用户拍摄或选中的照片 | 原图及方向信息。取消、权限拒绝、相机不可用、文件不可读分别返回。 |
| ImageCorrection | 原图、方向、自动或手动四边形 | 校正图和应用的几何参数。未检测到边界时允许手调。 |
| OCRService | 校正图、识别语言 | OCR 原始文字、区域及可用的置信信息。无文字、取消和错误单独报告。 |
| FieldParser | OCR 原始观察结果 | 结构化候选及可定位的文字来源。缺失或无法确认的字段留空。 |
| CardRepository | 草稿、ID、查询条件或分组 | 查询、保存、更新、删除结果，写入失败提供可恢复错误。 |
| ContactExporter | 已确认联系人、导出目标 | 通讯录写入结果或可分享的 VCF 文件。权限拒绝、取消、写入失败分别报告。 |

搜索接口支持姓名、公司、职位、电话、邮箱和分组条件。已保存值是导出的唯一来源，姓名、公司、职位、电话、邮箱和地址按字段映射，多电话及邮箱保留标签或类型。系统通讯录拒绝授权时，VCF 入口仍可使用。VCF 需校验转义、中文字符和重复属性的往返读取。
