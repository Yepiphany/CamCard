# 开发与交付计划

项目以[阶段任务](tasks.md)划分交付。阶段 1 固定需求、规格、数据和验收方法。阶段 2 建立可启动的 Xcode 工程和模拟器测试基线。阶段 3 至 5 按采集识别、人工确认、管理导出顺序交付，每个阶段验收后进入下一阶段。阶段 6 汇总回归、观察差异和演示材料。

每次开发先确定需求编号、修改范围、可观察结果和验证步骤。交付记录包含构建与测试结果、未通过项、证据、提交号。按项目约定，本地提交完成后经用户确认再推送。

课程演示使用 Xcode 模拟器。阶段 2 建立共享 Scheme，记录可用模拟器，并在 README 中补录实际通过的构建及测试命令。阶段 6 保留可复现的演示构建与对应提交，记录测试数据初始化、复测和回退步骤。通过课程平台提交项目源码和课程报告。交付时使用同一 Git 提交打包源码与文档，附模拟器运行步骤和脱敏测试证据。
