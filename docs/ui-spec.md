# 界面规格

下表概述当前界面行为。表后的对照记录保留各阶段当时的界面和差异。原版观察另见[黑盒规格](spec.md)。

| 页面 | 布局与入口 | 行为与状态 |
| --- | --- | --- |
| 名片夹 | 顶部搜索和分组入口，内容区有计数、空引导或按日期显示的名片。底部中央打开扫描。 | 点条目进详情。首次保存后返回显示新增项，删除后更新计数。 |
| 扫描 | 深色背景，提供单张拍摄、连续拍摄、多张拍摄和二维码模式。 | 取景区随模式切换。设备端提供实时预览、快门和补光，拍摄后可校对或重拍。模拟器使用相册继续。 |
| 相册 | 选择图片后显示已选数量，完成按钮进入识别。 | 处理取消、有限访问、拒绝和无法读取。取消返回扫描且不产生草稿。 |
| 编辑名片 | 顶部重新拍摄及保存。中间显示校正预览和文字高亮。下方为识别语言及可编辑字段。 | 首次导入自动校正并识别。多值可分别添加、编辑和删除。识别空结果仍允许人工录入或退出。 |
| 手动裁剪 | 原图、蓝色边框及四角四边控制点，顶部取消和完成。 | 取消恢复原编辑状态。确认后更新预览并触发重识别。完成行为待与原版对照。 |
| 详情 | 展示名片图像及联系字段，提供编辑、备注、分组、更多菜单和通讯录入口。 | 保存后首先进入详情。可查看原图、删除名片、打开系统联系方式及导出 VCF。VCF 为项目补充入口。 |
| 备注与拜访日志 | 从详情或名片夹快捷操作进入备注列表，底部新增按钮可选择普通备注或拜访日志。 | 备注支持文本、照片、录音和位置。拜访日志可记录方式、结果和回访时间，保存后返回备注列表。 |
| 搜索与分组 | 搜索页有返回和搜索框，分组页有搜索及新建入口。 | 命中时显示名片缩略图、计数和高亮，未命中时显示包含搜索词的空状态。新建分组显示 0 张，从名片夹添加组员后更新计数及列表。 |

界面测试以固定模拟器规格、语言和同一测试数据复现。记录页面的布局、文案、返回行为、按钮可用状态和权限反馈。原版的商业推广及公开人脉功能依照项目边界处理。

## 第二阶段界面基线

启动直接进入名片夹。默认显示 0 张和空状态。使用 `--demo-cards` 启动时，按日期显示一张合成名片。点名片进入详情，核对姓名、公司、职位和联系字段，返回后仍显示同一条目。扫描按钮打开可关闭的扫描页框架。相机与相册在第三阶段接入，搜索与分组入口在第五阶段接入。

## 原版布局对照

2026-11-06 通过 iPhone 镜像复核。名片夹采用浅灰背景、胶囊搜索框、四个快捷入口、白色名片区和五位底栏。名片区右上显示「管理」，有名片时按日期显示缩略图、姓名、职位和公司。空状态沿用首次观察的入门引导。详情页采用深蓝标题区、白色联系人摘要、四项彩色操作、分组和备注区、联系字段及底栏。扫描页采用深色布局、竖向取景框、顶部识别模式、底部相册和快门。

现阶段使用系统图标和合成名片内容重建这些布局。原版同屏但未实现的入口以禁用状态呈现，随对应功能接入。首页推广、企业及登录功能按既定范围排除。每阶段对照原版的布局、文案、控件状态和返回行为，第六阶段进行逐页视觉验收。

## 第三阶段扫描与识别

扫描页的相册按钮打开系统照片选择器，快门打开系统相机。相机支持预览、使用照片、重拍和取消。导入或确认照片后，应用尝试自动裁剪和识别。检测不到边界时展示原图和手动裁剪入口。识别结果页显示校正图、文字区域和 OCR 原文。点裁剪图标可拖动四角，使用旋转按钮调整方向，确认后重新识别，取消则保留上次结果。可关闭扫描或重新选择照片。第三阶段的结果保留在扫描会话，人工确认和保存属于下一阶段。

## 第三阶段视觉复核

2026-11-07 通过 iPhone 镜像查看原版，并在 Device Hub 查看 iPhone 18 Pro（iOS 27.2）上的复刻版。两端使用不同名片，本次对照页面结构和交互，未做同图像素比较。

| 页面 | 原版实测 | 复刻版实测 | 结论 |
| --- | --- | --- | --- |
| 名片夹 | 胶囊搜索框、四项快捷入口、名片区、五位底栏。消息图标带红点。 | 页面骨架对应。图标及部分间距不同，消息图标无红点，搜索和分组入口仍为静态展示。 | 局部一致。 |
| 扫描 | 当前选中基础识别。取景框含靠近名片提示和照亮入口。单张拍摄有蓝色指示条，旁边还有多张拍摄及二维码入口。 | 默认突出 AI 高精度识别，识别模式为静态展示。缺少取景提示、照亮入口和部分模式。暗色背景上的系统状态栏对比度偏低。 | 布局和状态有差异。 |
| 相册 | 自定义全屏网格。勾选后显示数量，点击底部「完成」才进入识别。 | iOS 系统照片选择器，点选一张后直接进入识别。 | 界面及操作顺序不同。 |
| 识别后 | 进入「编辑名片」。高亮图下方有识别语言、结构化字段，右上为「保存」。 | 进入「识别结果」。高亮图下方为语言代码和 OCR 原文，右上为「关闭」。 | 编辑与保存尚待第四阶段。 |
| 手动裁剪 | 黑色背景，四角及四边共八个手柄。顶部取消和完成。 | 黑色背景，四个角点。顶部另有旋转，完成按钮颜色也不同。 | 控件与样式有差异。 |

镜像提示无法从 Mac 使用 iPhone 相机，本次未对照实拍预览。视觉复核未通过完全复刻标准。课程范围内的差异应在对应功能阶段解决并复测。

## 视觉差异修订

相册使用全屏网格，单张照片勾选后显示计数，点击「完成」才进入识别。裁剪页保留旋转，并补齐四个边中点。识别后进入「编辑名片」，显示语言、字段和保存。可展开 OCR 原文用于核对。保存写入当前名片夹并打开详情。名片夹搜索在当前记录上匹配，分组入口打开分组列表。

## 第四阶段镜像观察

- 原版编辑页使用浅灰底，顶部依次为「重新拍摄」「编辑名片」「保存」。下方是圆角高亮预览，底部有两个页点，右下有蓝色裁剪入口。字段按白色区块分组，先显示高精度开关、识别语言和姓名，接着显示联系方式及公司、职位等字段。
- 点击姓名打开子页，顶部显示名片预览。中文姓名分为姓和名字，另有拼音区和「显示隐藏项」入口。公司和职位可出现双语的独立行。
- 本次导入使用原版已获授权的照片。点击「重新拍摄」返回扫描，转场中名片夹出现新增条目。项目遵循课程要求，仅在人工确认保存后新增条目。原版观察仅记录脱敏描述。
- 验收检查编辑页结构、姓名入口、多值字段和保存跳转。端侧高精度与原版服务行为分别记录。字段模型中的姓名、公司、职位各为一个值。
