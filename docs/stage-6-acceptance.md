# 第六阶段验收记录

以第五阶段提交 `a82889a` 为基线。原版通过 iPhone 镜像观察，复刻版在 iPhone 18 Pro 模拟器运行，系统为 iOS 27.2（24B8117），Xcode 为 27.2（27B52）。只使用合成测试数据及复刻版截图作为共享证据。镜像中使用的是原版既有名片，原版和复刻版未使用同图逐像素对照。

下文先记录第六阶段首轮对照与测试，后续更新集中在[第六阶段补查记录](#第六阶段补查记录)。T06、T13 和 T20 的最终覆盖情况见补查表。

## 首轮界面对照与处理

| 场景 | 原版实测 | 复刻处理及差异 |
| --- | --- | --- |
| 名片夹 | 列表右侧省略号打开四行操作，顶部加号展开新增菜单。 | 重建两个菜单及当前条目的分组和备注跳转。分享使用课程所需的本地 VCF。通讯录备份、导入联系人和雷达等入口保留视觉位置。 |
| 添加名片 | 添加页独立列出相册导入、手动输入和其他来源。手动输入首屏有图片占位及分段字段。 | 相册直达选图，手动输入可附图并保存到名片夹。附图沿用原图，不运行 OCR 或透视校正。自动保存通讯录开关按课程的显式导出流程保留为禁用状态。 |
| 搜索 | 返回箭头与白色搜索胶囊同排，空查询显示历史词条与人脉搜索区块。 | 对齐顶栏、历史词条、清空和复用。保存最近 10 条本地查询。人脉搜索为禁用状态，原版推广插图以系统图标表示。 |
| 详情 | 蓝色标题区带名片底纹，摘要有阴影，电话、地址和备注使用蓝、黄、绿色图标。 | 调整标题居中、底纹、摘要阴影及图标颜色。系统状态栏、图标与间距仍有差异。 |
| 编辑已保存名片 | 左取消右保存，上方为高亮图和页点，下方分块展示姓名、电话、邮箱及公司。 | 实现两张图切换、分区和添加入口。保存前留在草稿，取消丢弃改动。公司及职位第二组可人工编辑，OCR 仍按既有规则提取第一组。 |
| 姓名 | 子页包含姓名、拼音和隐藏项，原版会聚焦到姓名识别区域。 | 扫描与已保存编辑共用子页，OCR 可定位时显示姓名裁切。拼音以本地音译预填，支持修正。隐藏项和部门可以随名片保存。复姓切分和拼音读音可能与原版不同。 |
| 其他管理 | 原版有拜访日志和附件、邀请、提醒等入口。 | 普通文本备注和本地分组覆盖课程范围。其余入口、图标和外部服务仍有差异。 |

镜像在本轮观察完成后因闲置重新锁定。真实相机预览和拍摄未进行真机测试。商业首页、登录、团队及公开人脉搜索依照项目边界处理。

## 演示流程

启动模拟器中的 CamCard，从相册导入 CC-001，检查识别结果和裁剪，进入姓名子页后返回并保存。打开详情编辑、分组和添加普通备注，然后退出并重启验证持久化。最后从详情导出 VCF，再回名片夹演示查询和条目快捷菜单。

## 第六阶段补查记录

原版通过 iPhone 镜像重新观察扫描四种模式、名片详情及备注。备注快捷入口跳到列表；新增后可选普通备注或拜访日志。拜访表单有四种方式、可编辑内容及结果、回访滚轮和媒体栏。参考 App 的相机显示「无法从 Mac 使用 iPhone 相机」，未在原版授予额外权限或写入测试备注。

| 补查项 | 处理及验证 |
| --- | --- |
| 扫描 | 四种模式及取景区，真实设备分支使用 AVFoundation 预览、拍摄及补光。连续模式可从相册批量选取并逐张确认；多张模式从一张图尝试分离多个边界。二维码可通过实时元数据或相册解码和复制，商业在线交换不在范围内。 |
| R06 | 修复 OCR 结果变化时丢弃姓名细项。模型回归覆盖手动清空、昵称、未修改姓名细项随识别更新，以及人工值与一轮候选碰巧相同的连续重识别。 |
| T06 / T20 | 定向测试实际导入 CC-016 和 CC-017，拖动角点并确认重新识别。损坏数据经相册确认后的同一入口注入，报错后可继续导入。 |
| T13 | 测试接收器断言电话、邮件及网页 URL，没有发起真实电话、邮件或网络访问。 |
| 详情与备注 | 对齐详情操作区、底栏、备注列表与拜访表单，支持本地收藏、拜访日志及附件。模拟器验证表单、方式切换、回访滚轮及文本保存；独立检查验证旧备注读取、附件保存、重开与清理。 |
| OCR | 在相同的合成集上复跑，存在字段 94/97，缺失字段误填 0/135。原文及候选与原验收日志一致。 |

真机相机预览、拍摄与补光仍未验证；备注的麦克风、相机、位置权限及系统通知实际送达也未做硬件验收。设备状态栏、原版图标和系统控件仍有视觉差异。原版和项目尚未用同图完成 OCR 或像素级对照，因此本记录不判定界面已完全一致。

此次相册补查时，原版只授权了一张既有名片，没有项目的合成样本；未扩大原版相册权限。

模拟器完整 UI 套件 12 项通过。后续详情状态栏修订后定向测试 5 项通过；最终扫描与相册布局修订后定向测试 3 项通过，覆盖相册、扫码模式、坏图恢复、无文字提示和手动裁剪。模拟器相机不可用路径也通过定向复测。另以模拟器命令行执行了姓名草稿、合成二维码及附件数据检查。iOS 设备目标编译通过，未安装到真机。
