# 验收标准

按课程 T01–T20 编号记录输入、步骤、期望、结果及证据。安装后清空应用测试数据，使用简体中文和固定模拟设备。每项保留构建标识、设备与系统版本、样本 ID 和截图或日志。已观察的跳转以[黑盒规格](spec.md)为依据。T03 和 T04 中依赖真实相机的部分记为未验证，不计为模拟器通过。

| 用例 | 需求 | 操作与通过条件 |
| --- | --- | --- |
| T01 首次打开 | R01 | 清空数据后启动，名片夹显示 0 张、空状态和扫描入口。 |
| T02 进入扫描 | R02 | 点中央扫描按钮，出现扫描页及相册入口。关闭回名片夹。 |
| T03 权限 | R02 | 注入允许和拒绝状态，检查界面反馈及相册替代入口。真实相机权限与画面联动记为未验证。 |
| T04 拍摄 | R02 | 检查实现具备预览、拍摄、重拍与确认路径。真机画面及实际拍摄记为未验证。 |
| T05 导入 | R02 | 选 CC-001 并确认，进入识别和编辑。取消选图时计数不变。 |
| T06 边界 | R03 | 导入 CC-016 或 CC-017，对照原图检查边界、透视校正及拖动控制点。分别取消和确认，核对预览是否回退或更新。 |
| T07 OCR | R04 | 导入 CC-001、CC-002 和 CC-004，保留 OCR 原文并逐项核对。 |
| T08 字段提取 | R05 | 对 29 个计分样本比较解析字段，记录字段级准确率及与原版差异。 |
| T09 缺失字段 | R05 | 导入 CC-008 或 CC-028，网站及不存在的联系方式保持为空。 |
| T10 多值 | R05 | 导入 CC-006 和 CC-027，核对号码类别及多个邮箱。无标签号码用 CC-026 检查是否发生臆断分类。 |
| T11 人工修订 | R06 | 修改错误字段并清空另一项，保存后详情显示最终值，原始识别结果可用于核对。 |
| T12 保存 | R01、R06 | 点保存先进入详情，返回名片夹新增一条。重复触发保存不产生重复条目。 |
| T13 详情 | R07 | 打开条目，核对原图和已保存字段。用测试替身检查电话、邮件、网站的系统跳转参数。 |
| T14 编辑 | R07 | 修改公司并保存，详情与列表同步。再次修改并取消，保留上次保存值。 |
| T15 搜索 | R08 | 分别用姓名、公司、职位、电话和邮箱搜索，检查正确结果及无匹配反馈。 |
| T16 分组 | R08 | 新建组、加入名片、按组筛选并删除组，名片记录仍存在。保存备注后重新打开核对。 |
| T17 删除 | R01、R07 | 删除前可取消。确认后列表、计数和搜索同步更新。 |
| T18 持久化 | R09 | 保存图像、手改字段、组和备注，终止应用并重新打开，逐项核对。 |
| T19 导出 | R10 | 使用合成样本存入模拟器通讯录并核对字段；导出 VCF 后重新读取，核对同样字段及多值。 |
| T20 异常 | R02–R06、R10 | 逐项测试相册拒绝、取消、文件不可读、空字段、CC-024 严重失焦、CC-030 无名片及通讯录拒绝。界面可恢复，通讯录拒绝后仍可导出 VCF。 |

OCR 和字段提取用[固定样本与标准答案](../tests/fixtures/business-cards/README.md)量化。分别记录存在字段的准确率及缺失字段的误填率，按语言和场景归纳差异。课程未给出数值门槛，报告实测值。确定性且在模拟器验收范围内的路径须全部通过。原版补充观察未完成的场景记录证据状态，补齐后再判定行为是否一致。

## 第二阶段冒烟验证

- S2-01 对应 T01。默认启动后显示名片夹、0 张、空引导和扫描入口。
- S2-02 对应 T02。点扫描后显示扫描页框架，关闭后返回空名片夹。相机和相册流程按后续阶段验收。
- S2-03 对应 T13。用 `--demo-cards` 启动，打开合成名片并核对姓名、公司和联系字段，再返回列表。
